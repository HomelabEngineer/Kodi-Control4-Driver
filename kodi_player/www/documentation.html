Kodi (Open Source)

IP control for Kodi 19+ over Kodi's JSON-RPC WebSocket (port 9090), with real-time playback status, the full remote/D-pad command set, and a link for the companion Kodi Movies driver, which browses the Kodi movie library on Navigators and Halo remotes and plays the selected movie.

Kodi setup

  1. Kodi → Settings → Services → Control: turn on Allow remote control via HTTP and Allow remote control from applications on other systems.
  2. Note the web server port (default 8080), username and password. Kodi Movies reads the library and artwork through the web server.
  3. Give the Kodi device a fixed IP address (DHCP reservation).

Composer setup

  1. Add this driver. Two devices appear: Kodi (the media player rooms select) and Kodi Virtual Switcher (plumbing, hidden from rooms).
  2. Set IP Address, Kodi HTTP Port, Kodi Username and Kodi Password.
  3. Connections → bind Kodi Virtual Switcher → HDMI OUTPUT to the TV or AVR input Kodi is plugged into. (This replaces the media player's own HDMI output in the original driver; the internal links between the player and the switcher bind themselves.)
  4. Add the room's video endpoint as usual so Kodi appears under Watch.
  5. Optional: add Kodi Movies. Its links to this driver normally bind automatically. If not, bind Kodi Movies → Kodi Player to this driver's Kodi Library Control, and the Kodi Movies Link and AV connections to the Virtual Switcher's Kodi Movies Link and Kodi Movies AV. The Library Link property shows the result.

What happens when a movie is picked in Kodi Movies

  1. This driver selects Kodi as the video source in the Navigator's room, so the room turns on the TV/AVR and switches inputs the normal Control4 way.
  2. While that launch is in progress, the room's ON does not send Kodi Home or start PM4K.
  3. After Play Delay After Room On (skipped if the room is already on Kodi) and once the WebSocket is connected, the movie is opened with Player.Open, resuming or starting over per Resume Behavior.
  4. If Kodi cannot be reached within Library Play Timeout, the Navigator is told the movie could not start.

Programming

Events: Playback Started, Paused, Resumed, Stopped, Ended, Library Movie Launched — e.g. dim the lights when a movie starts.

Commands: Kodi Action (any Kodi action name such as osd), Show Notification, Open Movies Library, Scan Video Library.

Actions: Reconnect / Disconnect WebSocket, Scan Kodi Video Library, Refresh Linked Kodi Movies.

Troubleshooting

  • WebSocket Status stays Disconnected: check the IP, that Kodi is running, and the "applications on other systems" setting. Turn on Debug Mode and watch the Lua output.
  • Room turns on but the movie doesn't start: raise Play Delay After Room On (some TVs drop the first seconds of HDMI), and check Library Play Timeout.
  • Kodi Movies says "Not linked": see Composer setup step 5.
