Kodi Movies (Open Source)

Shows the movie library of a linked Kodi (Open Source) player on Control4 Navigators (T3/T4/T5 touchscreens, the Control4 app) and Halo remotes — posters, titles, year, runtime, plot and more. Tap a movie and the room turns on with Kodi as the source, then the movie starts.

Requirements

  • Control4 OS 3.1 or later (for the details screen); the Kodi (Open Source) driver installed and connected.
  • Kodi's web server enabled (Settings → Services → Control → Allow remote control via HTTP). Port, username and password are set on the Kodi driver, not here.

Setup

  1. Add Kodi Movies to the project (one per Kodi player; it serves every room).
  2. Its connections usually bind to the Kodi driver automatically. If Kodi Player shows "Not linked", bind in Connections:
    • Kodi Movies → Kodi Player → Kodi driver Kodi Library Control
    • Kodi Movies Link and Kodi Movies AV → Kodi Virtual Switcher inputs of the same names (this gives the service a route to the rooms Kodi is in).
  3. Refresh Navigators. Kodi Movies appears in the rooms where Kodi is a video source.

Tapping a movie plays it (or opens its details, per Movie Tap Action). The item menu offers Play, Resume, Play From Beginning, Details and Mark as Watched/Unwatched. The details screen shows the poster or fanart, year, rating and certification, runtime, genres, director, tagline and full plot.

Programming

Event: Movie Selected. Variable: LAST_MOVIE_SELECTED. Actions: Refresh Library, Re-link to Kodi Player.

Troubleshooting

  • Posters missing: each Navigator loads artwork itself. With Kodi Web Server Only (or for local/NAS artwork) every touchscreen, phone and Halo must be able to reach Kodi's web server port.
  • "Couldn't load the Kodi library" / HTTP 401: check the web server port, username and password on the Kodi driver.
  • Kodi Movies doesn't appear in a room: confirm the Link and AV bindings to the Kodi Virtual Switcher, and that Kodi is a video source in that room.
